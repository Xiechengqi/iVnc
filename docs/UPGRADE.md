# 网页升级与 GitHub 代理回退

在“设置 → 重启或升级”勾选“升级到最新版本”后，会显示“使用 GitHub 中国代理”复选框。默认不勾选；勾选后显示代理下拉框，默认选择 `sina.dev`，也可选择 `httptunnel.top/gh` 或“自定义代理”。选择自定义代理后填写地址前缀，例如 `https://example.com/gh/`；省略协议时补全 HTTPS，末尾斜杠自动补齐。

只有确认“升级并重启”才执行下载。代理选项仅用于本次升级，不写入全局配置；取消或重新打开弹窗后恢复默认值。未勾选升级时，隐藏并禁用代理相关输入，确认按钮只执行重启。

## 来源顺序

未勾选代理时，程序下载与原有版本检查均自动按以下顺序请求，无需配置：

1. GitHub 原始 URL。
2. 在原始 URL 前加 `https://sina.dev/`。
3. 在原始 URL 前加 `https://httptunnel.top/gh/`。

例如 amd64 程序的第三个请求为：

```text
https://httptunnel.top/gh/https://github.com/Xiechengqi/iVnc/releases/download/latest/ivnc-linux-amd64
```

勾选代理后，程序下载直接从所选代理开始，避免 GitHub 可连接但下载很慢时一直等待原站：

| 选择 | 程序下载顺序 |
| --- | --- |
| sina.dev（默认） | sina.dev → httptunnel.top/gh → GitHub 原站 |
| httptunnel.top/gh | httptunnel.top/gh → sina.dev → GitHub 原站 |
| 自定义代理 | 自定义代理 → sina.dev → httptunnel.top/gh → GitHub 原站 |

重复的来源会去重，例如自定义地址填写 `sina.dev` 时不会重复请求它。每个代理都包装同一个原始 GitHub URL，互不嵌套；任一来源下载成功后便停止请求后续来源。独立的版本检查继续沿用原有自动顺序。实现参考 Miao 的 GitHub 下载代理前缀方式，这里配置的是 URL 前缀，与浏览器应用的 HTTP/SOCKS 流量代理无关。

网页和服务端均校验地址，接受 HTTP(S) 前缀，拒绝账号密码、查询参数、片段、空白／控制字符和过长地址。无效输入在升级启动前报告；程序下载目标仍是当前架构的固定官方发布文件。

升级 WebSocket 沿用认证和同源校验，新增可选查询参数 `github_proxy`，值为 URL 编码后的代理前缀。旧客户端不传该参数时保持原有行为。服务端在接受 WebSocket 和保存应用状态前完成校验；下载日志显示所选代理及实际尝试的来源。

## 失败与超时

连接失败、HTTP 非 200、响应头超时、下载中断或停滞都会切换来源；版本检查也将 JSON 解析失败或缺少有效版本号视为来源失败。代理返回的 HTML 等错误页、错误架构、过小或不完整的程序不进入安装步骤，而是尝试下一来源。

- 每个来源最多等待响应头 8 秒；版本信息的整个请求最多 10 秒。
- 每次程序下载最多 300 秒，连续 30 秒没有收到数据便回退。每个来源有独立预算。
- 下载日志显示当前来源、切换原因和进度；低速下载定期按已收数据刷新日志。切换来源时进度重新开始，已下载的半成品会清除，不续写其他来源的字节。
- 候选来源全部失败才结束升级并汇总原因；自定义代理最多有四个候选来源。本地创建、写入或清理文件失败时直接报告具体错误，切换网络来源无法修复这些错误。

下载成功前只写安装目录中的临时文件。候选程序必须满足原有最小大小要求，并通过 Linux ELF 64 位格式、当前 CPU 架构及可用 Content-Length 检查。之后沿用现有备份、权限、替换、`--version` 验证与重启流程。全部下载失败时清理临时文件，不进入备份、替换或重启。

```sh
cargo test --lib --features tls --offline web::github_update::tests
cargo test --lib --features tls --offline web::http_server::tests
cargo test --lib --features tls --offline
cargo build --features tls --bin ivnc --offline
CHROME_BIN=/usr/bin/google-chrome npm --prefix web/ivnc run test:settings
npm --prefix web/ivnc run build
cargo fmt --check
git diff --check
```
