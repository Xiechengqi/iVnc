# 设置关机功能 Review

日期：2026-11-16。

“设置”顶部在“重启或升级”右侧增加“关机”，完整控制台与精简设置页共用实现。确认框默认聚焦取消，明确提示保存应用运行状态、关闭连接并退出 iVnc。提交期间锁定弹窗与重复操作，正常响应后展示请求已接受。

## 审查结论

- `POST /api/shutdown` 沿用认证、同源与会话 CSRF 检查；认证关闭时也拒绝外站 Origin。GET 不执行关机，内部 worker 不开放该接口。
- 主循环未初始化返回 503。正常请求先返回 202，再触发现有退出标志，复用信号退出的清理流程：保存应用运行状态、停止应用与内置代理、停止视频管线、关闭运行时、清理环境及 Wayland socket，最终正常返回并以 0 退出。
- 真实 Chromium 验证发现，未读取 Fetch 正文时，浏览器测试的响应完成等待不会结束。现已在超时保护内读取并校验完整确认正文；无效或截断响应、网络中断、超时均不会显示请求已接受。页面离开也会中止正文读取并释放弹窗。
- 关机不安排重启；部署说明采用 `Restart=on-failure`。外部管理器的始终重启策略仍可能重新启动已正常退出的进程，需要按部署需求调整。
- 已验证范围内无遗留阻塞问题。
