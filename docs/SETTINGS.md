# 设置入口与账户、服务操作

底部 toolbar 的齿轮打开“设置”，保留“概览／应用／连接质量”导航。顶部右侧依次提供“修改密码”“重启或升级”、语言切换与退出图标。底部工具区及窄屏“更多工具”不再提供这三个独立操作。

桌面显示图标与文字；窄屏的两个新增操作显示图标，保留可访问名称，触控区域至少 40×44 CSS 像素。右侧操作区固定在导航旁，左侧导航可以横向滚动。设置与子弹窗适应可视区域，软键盘弹出后仍可滚动访问确认按钮。

## 操作行为

- 修改密码打开独立表单，校验长度与确认密码，使用原有 `POST /api/change-password` 和 CSRF 机制。成功撤销所有连接的登录凭据，主页面与同源其他标签页回到登录页。网页修改沿用原有进程内行为，重启后恢复配置文件中的密码。
- 退出沿用 `POST /auth/logout`、跨标签通知及当前会话的媒体、输入和 WebSocket 撤销。认证关闭时隐藏改密和退出按钮，保留服务操作。
- 重启或升级先打开确认框，默认仅重启。确认重启才发送 `POST /api/restart`；勾选升级并确认才连接 `/api/upgrade/ws`。打开设置、切换导航、打开或取消确认框不会执行操作。
- 执行期间防止重复提交，阻止空白点击、Escape、取消及父弹窗最小化。失败后恢复关闭能力；升级连接中断且未收到重启阶段日志时，不显示成功。连续 120 秒没有有效升级日志时显示结果无法确认并允许关闭；关闭页面不代表后台升级已取消。
- 服务恢复最多等待约 30 秒，探测请求有独立超时；恢复后刷新同源主页面，通过原有登录流程处理服务重启导致的会话失效。

空闲状态下，取消、Escape 或点击子弹窗外只关闭当前子弹窗，设置保持打开，焦点返回操作按钮。子弹窗会阻断对应用画面、其他弹窗和底部 toolbar 的穿透输入。离开页面时清理请求、日志连接、轮询、计时器和遮罩。

## 控制台禁用与独立访问

`ui_features.console_enabled=false` 时，齿轮入口加载 `/settings.html`，只提供账户与服务操作，不请求控制台管理 API。共享操作组件也用于完整控制台，避免两套行为。原有 `/console`、应用管理、连接质量管理接口的访问限制继续由服务端执行；内部 worker 和应用专属视图不新增实例管理入口。

`/console` 保持可直接访问，页面名称改为“设置”；顶部操作支持独立页和主页面内嵌两种方式。精简设置页也可直接打开，继续受原有认证中间件保护。

## 验证

```sh
CHROME_BIN=/usr/bin/google-chrome npm --prefix web/ivnc run test:settings
IVNC_WEB_ROOT="$PWD/web/ivnc/dist" node scripts/auth_smoke.mjs
```

浏览器交互测试运行真实设置控制器、弹窗管理、完整控制台与精简页面，使用隔离的 WebSocket 日志服务验证升级分支；不调用运行实例的重启、升级接口。认证 smoke 使用独立数据目录和服务进程，验证真实登录、设置入口、改密与会话撤销。
