# 设置入口与账户、服务操作

底部 toolbar 的齿轮打开“设置”，提供“概览／应用／连接质量／高级”导航。顶部右侧依次提供“修改密码”“重启或升级”“关机”、语言切换与退出图标。底部工具区及窄屏“更多工具”不再提供账户、重启／升级的独立操作。

桌面显示图标与文字；窄屏的改密、重启／升级与关机操作显示图标，保留可访问名称，触控区域至少 40×44 CSS 像素。右侧操作区固定在导航旁，左侧导航可以横向滚动。设置与子弹窗适应可视区域，软键盘弹出后仍可滚动访问确认按钮。

## 操作行为

- 修改密码打开独立表单，校验长度与确认密码，使用原有 `POST /api/change-password` 和 CSRF 机制。成功撤销所有连接的登录凭据，主页面与同源其他标签页回到登录页。网页修改沿用原有进程内行为，重启后恢复配置文件中的密码。
- 退出沿用 `POST /auth/logout`、跨标签通知及当前会话的媒体、输入和 WebSocket 撤销。认证关闭时隐藏改密和退出按钮，保留服务操作。
- 重启或升级先打开确认框，默认仅重启。勾选升级后显示“使用 GitHub 中国代理”复选框，默认不勾选；勾选后显示代理选择，默认 `sina.dev`，也支持 `httptunnel.top/gh` 和自定义地址。确认重启才发送 `POST /api/restart`；勾选升级并确认才连接 `/api/upgrade/ws`，传递本次代理选择。隐藏的代理输入不会阻止仅重启或不使用代理的提交。打开设置、切换导航、打开或取消确认框不会执行操作。
- 关机打开二次确认框，默认聚焦“取消”；只有点击“确认关机”才发送 `POST /api/shutdown`。请求期间锁定确认框及父弹窗，避免重复提交。取消、Escape、空白点击不发送关机请求。完整读取并校验响应后显示“关机请求已接受”，不轮询服务恢复或自动刷新；连接中断、响应不完整或超时只提示结果无法确认，读取响应正文同样受超时与页面离开清理保护。
- 执行期间防止重复提交，阻止空白点击、Escape、取消及父弹窗最小化。失败后恢复关闭能力；升级连接中断且未收到重启阶段日志时，不显示成功。连续 120 秒没有有效升级日志时显示结果无法确认并允许关闭；关闭页面不代表后台升级已取消。
- 服务恢复最多等待约 30 秒，探测请求有独立超时；恢复后刷新同源主页面，通过原有登录流程处理服务重启导致的会话失效。

未选择代理时，升级请求按“GitHub 原站 → sina.dev → httptunnel.top/gh”自动回退。手动启用代理后，程序优先从所选代理下载，其他代理及原站作为后续候选；来源失败或下载中断时从下一来源重新下载。代理地址须为 HTTP(S) URL 前缀，前后端在执行前校验。版本检查保持原有自动顺序。详情见 [网页升级与 GitHub 代理回退](UPGRADE.md)。

空闲状态下，取消、Escape 或点击子弹窗外只关闭当前子弹窗，设置保持打开，焦点返回操作按钮。子弹窗会阻断对应用画面、其他弹窗和底部 toolbar 的穿透输入。离开页面时清理请求、日志连接、轮询、计时器和遮罩。

## 关机与进程生命周期

`POST /api/shutdown` 使用现有认证和会话 CSRF 校验，禁止 GET 和跨源浏览器请求；认证关闭时同样拒绝携带外站 Origin 的关机请求。内部 worker 不开放实例关机接口。主循环尚未初始化时返回 503，不显示已接受。

正常请求返回 `202 {"ok":true,"mode":"shutdown"}`，短暂留出响应发送时间后设置主循环的退出标志。之后复用 Ctrl+C／SIGTERM 的退出流程：保存应用运行状态、停止托管应用与内置代理、停止视频管线、关闭异步运行时并清理环境和 Wayland socket，最终以退出码 0 结束 iVnc 进程。

关机不会安排自重启。服务管理器应使用 `Restart=on-failure`，仓库的 service 文件及部署示例采用此策略；已有部署若设置 `Restart=always` 或容器的始终重启策略，进程正常退出后仍会被外部管理器重新启动，需按期望调整部署策略。

## 控制台禁用与独立访问

`ui_features.console_enabled=false` 时，齿轮入口加载 `/settings.html`，提供“常规／高级”分页及账户与服务操作，不请求控制台管理 API。高级页复用完整设置的 IP 白名单组件和独立认证接口。原有 `/console`、应用管理、连接质量管理接口的访问限制继续由服务端执行；内部 worker 和应用专属视图不新增实例管理入口。

`/console` 保持可直接访问，页面名称改为“设置”；顶部操作支持独立页和主页面内嵌两种方式。精简设置页也可直接打开，继续受原有认证中间件保护。

## 连接质量：同步图片和富文本

默认开启；明确保存的关闭设置在升级后保留。设置同时应用于主桌面和本机独立应用，新启动和已运行的独立应用保持一致。远程应用使用来源实例的策略。HTTPS 支持图片直接复制，HTTP 提供原图预览、浏览器原生复制和下载；详细流程及限制见 [剪贴板](CLIPBOARD.md#图片复制与实例策略)。

## 高级：IP 白名单

高级页按需读取配置，切换语言或分页保留未保存的草稿；只有点击“保存并应用”才发送写请求。输入框保留原始行号供校验提示，保存失败可直接修改重试。当前客户端 IP、命中状态和通过白名单登录时的会话撤销提示均由服务端认证信息驱动。规则与来源识别说明见 [IP 白名单免密登录](AUTHENTICATION.md#ip-白名单免密登录)。

完整实现和本地验证记录见 [IP 免密登录 Review](IP_LOGIN_REVIEW.md)。
