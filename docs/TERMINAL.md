# Web 终端样式与会话

toolbar 的终端弹窗使用 xterm，通过 `/terminal/ws` 连接服务端 PTY。每条 `output` 消息携带 Base64 编码的原始字节，由 xterm 解析并显示。

## 重复字符问题

xterm 为测量字宽，会在 `.xterm-char-measure-element` 中放入重复 32 次的字符；DOM 字体测量回退路径还会创建重复的 `W`。这些节点由官方 CSS 隐藏并移出正常布局，仍保留可测量宽度。

桌面入口由 `index.html` 在取得配置后动态创建 module script 加载。此前普通 CSS import 被 Vite 提取到独立文件，但动态入口没有加载该文件，导致测量节点可见。初始 shell 提示符中的 `#` 因此显示为一串 `################################`。WebSocket 中并没有这串异常输出。

`ivnc-wr-core.js` 现在使用 `@xterm/xterm/css/xterm.css?inline` 引入完整官方样式，在终端创建前注入 `#ivnc-terminal-styles`，同一 document 只注入一次。开发环境与生产资源使用相同路径，不依赖构建文件名，也不复制依赖库的 CSS。

测量节点不能用 `display:none` 隐藏，否则宽度为零。输入 textarea、IME composition view 和辅助功能节点均由官方样式管理；应用只负责弹窗外观和尺寸。

## 显示与会话行为

- 首次打开、重连和重新显示不会自动清屏，启动阶段的真实输出保留。原有连接后 300ms 的自动清屏已移除。
- 最小化隐藏弹窗，保留终端、WebSocket、PTY 和滚动历史。重新显示后适配可见容器尺寸。
- 连接断开后沿用现有重连机制，服务端为新 WebSocket 创建新的 shell；前端保留原有显示历史。
- 真实命令输出的重复字符照常显示。修复只涉及测量节点的样式，不过滤输出数据。

## 背景模式

终端标题栏在最小化按钮左侧提供“半透明 / 不透明”切换按钮，文字表示当前模式，悬停提示表示点击后的目标模式。首次使用默认半透明：背景采用 `rgba(5, 6, 7, 0.85)`，即 85% 背景不透明度；不透明模式使用 `#050607`。标题栏叠加深色底以保持可读性，文字、光标和按钮不降低整体透明度。

背景仅由携带 `data-terminal-background` 的终端弹窗外层绘制，内容区与 xterm 默认背景透明，滚动容器的官方默认黑底通过终端专用样式覆盖，避免多层叠加遮住底层应用。xterm 在 `open()` 前启用 `allowTransparency`。切换不重建 xterm、不重连 WebSocket、不清屏、不改变 PTY 尺寸或滚动位置。程序显式输出的 ANSI 背景色仍按原有颜色显示；控制台和代理弹窗沿用不透明样式。

选择保存在同源浏览器的 `localStorage['ivnc.terminal.background']` 中，允许值为 `translucent`、`opaque`。最小化、重新打开和页面刷新均沿用已保存选择；同源页面通过原生 storage 事件同步模式，清除设置恢复半透明。缺失、无效或无法读取的记录均回退到半透明；写入失败时仍可切换，并在当前页面内记住选择。该偏好只作用于浏览器，不发送到服务端。

按钮支持鼠标、Enter 和 Space；鼠标切换后回到终端输入，键盘切换保留按钮焦点。按钮的按键与终端输入隔离，中文/英文文案及可访问状态随当前语言和模式更新。控制器销毁时清理语言和 storage 监听器。

## 窗口操作

终端标题栏支持拖动，四边和四角支持调整大小；按钮和内容区分别保留按钮操作、文字选择语义。使用指针捕获连续跟踪跨 iframe 的拖动，Esc 取消操作并恢复起始矩形。失焦、取消和最小化时结束当前手势，销毁时清理监听器。缩放时边缘命中区维持至少 6 个页面 CSS 像素。

`floating-window.js` 以页面 CSS 坐标管理位置，以未缩放的逻辑尺寸管理宽高，保留桌面缩放且不重复计算 DPR。窗口限制在统一工作区内，固定 toolbar 时扣除其高度，并保留 8px 边距。视口、DPR、手动分辨率或全屏变化后重新约束窗口，保证标题栏可操作。

容器变化以 60ms 节流适配 xterm，松手立即适配最终尺寸；同一连接只在行列改变时发送 resize。前后端共同限制为 20–400 列、5–160 行。拖动和调整大小保留当前 xterm、WebSocket、PTY 与历史。

标题栏图钉按钮默认关闭。置顶后终端高于普通工具浮窗，点击外部、切换应用或打开控制台/代理时保持显示且不抢焦点；用户仍可主动最小化，重新展开保留置顶。控制台子弹窗、密码和更新确认优先接收输入。置顶作用于网页内部。

窗口位置比例、逻辑宽高和置顶保存在当前标签页的 `sessionStorage['ivnc.terminal.window.v1:' + location.pathname]` 中。刷新后恢复并重新校正工作区；无效或不可用的存储回退到居中默认窗口和当前页面内存。背景偏好继续使用独立的 localStorage 设置。

主页面元素全屏使用包含桌面、toolbar 和浮层的共同根节点，避免移动已加载 iframe。浮窗激活时退出指针锁并释放键盘锁；全屏自动锁定跳过可见浮窗，用户可通过原有入口恢复远程锁定。嵌入视图沿用自身的全屏容器。控制台子弹窗的跨文档交互详见 [控制台 UI](CONSOLE_UI.md)。

## 验证

先构建前端，再构建包含这些资源的服务端：

```bash
npm --prefix web/ivnc run build
CARGO_INCREMENTAL=0 cargo build --features tls --bin ivnc
IVNC_BIN="$PWD/target/debug/ivnc" node scripts/terminal_smoke.mjs
IVNC_BIN="$PWD/target/debug/ivnc" node scripts/window_ui_smoke.mjs
IVNC_BIN="$PWD/target/debug/ivnc" node scripts/toolbar_smoke.mjs
```

终端 smoke 使用独立运行目录、端口、浏览器配置和 shell，默认清理成功运行的临时文件；失败保留日志、诊断数据和截图，可用 `KEEP_TMP=1` 保留成功运行的目录。测试 shell 禁用用户启动配置及历史写入。代理入口开启以检查弹窗样式，代理自动启动关闭，并为其指定独立端口。

覆盖官方样式、隐藏且可测量的辅助节点、启动输出、真实重复字符、Unicode 与字体变体、会话复用、尺寸与 DPR 变化、主桌面手动缩放、中文输入法预编辑与提交、复制粘贴、滚动历史、重连及 DOM 字体测量回退路径。

背景模式回归还覆盖真实截图像素（空白终端单元格和内边距）、鼠标与键盘切换、输入隔离、最小化与滚动位置保留、刷新恢复、同源设置同步、中英切换、无效记录和存储异常回退，以及控制台/代理样式隔离。截图使用已知红/绿背景验证半透明的实际合成色及不透明的完全遮盖；`KEEP_TMP=1` 保留 `translucent.png` 和 `opaque.png`。
