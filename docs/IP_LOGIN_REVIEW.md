# IP 白名单免密登录与密码可见性 Review

日期：2026-11-18。

## 实现范围

- 登录页增加输入框内的显示／隐藏密码图标，支持键盘、移动端、双语及选区保留。页面重新加载或恢复时隐藏密码。
- 完整设置增加“高级”，精简设置增加“常规／高级”，共享 IP 免密配置组件。支持按需加载、草稿保留、错误行提示和保存失败重试。
- IPv4、IPv6 与 CIDR 规则在服务端规范化、去重；配置默认关闭，保存后即时生效，重启保留。
- 免密登录建立正式、来源绑定的会话，复用 Cookie、CSRF、Origin、超时和撤销机制。主动退出后需要点击“免密进入”或使用密码。

## 整体审查

| 检查范围 | 结论 |
| --- | --- |
| 来源 IP | 默认只使用 TCP 对端。仅明确配置的可信代理可提供单个、有效且有界的 X-Forwarded-For 链；从右向左确定来源，IPv4 映射 IPv6 统一匹配 |
| 认证兼容 | 状态保持 kind=session，新增 method 区分密码和 IP 来源。遗留 Basic 缓存不阻止 IP 会话建立，密码会话不绑定 IP |
| Cookie 与浏览器边界 | 保留 Host/发布端口隔离、HttpOnly、SameSite、TLS Secure、重复 Cookie 拒绝及安全返回地址校验 |
| 写请求与代理 | 配置读写受原认证中间件保护；写入要求会话 CSRF 与同源 Origin。新设置路径明确排除在 Miao 路由与 CSRF 特例外 |
| 撤销 | 删除规则或关闭功能只撤销不再匹配的 IP 会话；密码会话与仍匹配的 IP 会话保留。信令关闭后的实际媒体仍受会话撤销控制 |
| 保存与失败 | 请求体、规则数量和读取文件有边界；0600 临时文件写入、同步后原子替换，再更新内存。写入失败保留策略，启动读取异常关闭 IP 免密 |
| 管理边界 | 高级配置可用于精简设置；原有控制台远程开关、worker 端点白名单及远程应用授权边界不扩大 |
| UI 行为 | 挂载、切换语言及分页不写配置；保存期间禁止重复操作。独立设置页会在自身 IP 权限被撤销后主动回到登录页 |

未发现阻塞问题。IP 白名单按服务端识别的来源授权，同一 NAT 来源的客户端共享匹配结果；HTTP 的传输属性、代理与媒体入口约束沿用原有设计，详见 [认证说明](AUTHENTICATION.md)。

## 回归中发现并修复的问题

1. 服务端重定向无法读取原 URL 的 fragment，登录页现在恢复浏览器继承的锚点，同时继续校验返回地址。
2. 移动 Chrome 在密码框切换类型后重置选区，增加渲染后的选区恢复；Chrome、WebKit 均验证通过。
3. 前端只接受浏览器 session，但 Basic 已认证状态原先会阻止自动引导；现在按是否存在有效浏览器会话决定免密引导。
4. 独立设置页没有媒体 WebSocket 撤销通知，IP 会话保存配置后会主动重新校验认证。
