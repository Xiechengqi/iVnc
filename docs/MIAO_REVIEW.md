# Miao 后台应用实施 Review

审查日期：2026-10-30。范围：iVnc 与相邻 Miao 仓库本次变更，包括生命周期、持久化、认证转发、控制台、Chrome 联动和构建发布流程。

以下为首次后台应用实施的历史记录；2026-11-02 的后续更新见文末，当前构建与部署要求以 [Miao 后台应用](MIAO.md) 为准。

## 结论

Miao 已作为 `builtin-miao` 内置后台应用接入。首次默认随 iVnc 启动，后续保留用户选择；应用列表与原代理入口使用同一个进程管理器。审查中发现的问题均已修复，当前未发现尚未解决的代码阻塞问题。

面板进程与代理内核运行偏好分别管理，宿主机开机启动沿用 iVnc 现有服务配置。节点、订阅、面板密码和原有 `$HOME/.miao` 数据继续由 Miao 管理。

## 审查发现与修复

| 发现 | 最终处理 |
| --- | --- |
| 通用应用恢复可能覆盖用户关闭自启动的选择 | Miao 使用独立的首次注册、自启动和恢复逻辑，排除五分钟运行状态恢复 |
| 并发启动、iVnc 异常退出可能造成重复实例或残留进程 | 串行化启停、配置目录锁、实例运行目录和进程组清理；关闭自启动时同样清理本实例残留 |
| 启动请求取消后，存活进程可能永久停留在未就绪状态 | Watchdog 完成后续就绪检查；丢失所有权的子进程由 Drop 清理 |
| 单纯端口探测可能误认其他程序 | 构建协议校验与运行时服务标识、协议版本、精确 PID 校验 |
| 嵌入面板的 iframe、认证 WebSocket 和绝对路径存在兼容问题 | 嵌入模式使用 SAMEORIGIN，保留 Host/Origin/Cookie，校验上游握手后升级；路径适配保留 WebSocket 常量 |
| Chrome 固定 SOCKS 端口与实际配置可能不一致 | 读取实际内核运行状态及 SOCKS 地址；桌面启动命令保持单行，满足 desktop-entry 校验 |
| 旧 Miao 产物可能被静默嵌入，构建缓存可能取错产物 | 校验嵌入协议 v1、下载缓存按 URL 区分、跟踪前端产物变化；不修改源二进制权限 |
| 路径迁移测试修改全局环境，造成并行配置测试偶发失败 | 使用隔离子进程和独立迁移目录，移除测试间环境污染 |

内置启动字段、删除和清除数据操作均在 API 层保护；管理员代理总开关优先于自启动与手动启动。嵌入模式关闭自动打开浏览器及面板自升级，升级由 iVnc 配套发布提供。

## 2026-11-02：OpenSSH 与免密码更新 Review

范围：本次 iVnc 与 Miao 的 OpenSSH 运行依赖、`--nopasswd`、认证引导、嵌入协议及回归脚本。未发现尚未解决的代码阻塞问题。

| 审查点 | 处理与结论 |
| --- | --- |
| VPS 部署提示 `SSH client unavailable` | Docker 运行镜像补齐 `openssh-client`，构建时执行 `ssh -V`；Miao 区分缺少程序、权限不足和其他启动错误，缺包时给出安装包名 |
| 免密码是否改写原密码或影响普通启动 | `--nopasswd` 仅对当前进程生效，不读取或改写认证文件；与设置密码参数互斥；真实二进制验证移除参数后恢复原密码登录 |
| 是否绕过管理接口与外层认证 | 浏览器通过同源 POST 自动建立会话；管理 API 仍需 Cookie，写操作保留 CSRF/Origin，WebSocket 保留会话/Origin；iVnc 未认证请求返回 401 |
| 只读状态探测是否产生会话 | 不创建 Cookie 或会话，避免宿主健康检查消耗会话额度；浏览器已有会话时复用 |
| 是否可能嵌入不支持新参数的旧 Miao | 协议升级为 v2；构建校验版本，就绪检测同时要求 `password_required: false`；iVnc 默认传入 `--nopasswd` |
| 网页是否仍要求初始化或显示无效密码操作 | 自动进入面板，隐藏改密/退出按钮，免密码模式的初始化与改密 API 返回 403 |

## 2026-11-02：`--proxy-ip` 与 Docker 参数透传 Review

iVnc 新增 `--proxy-ip <IP>`，通过类型化的 IPv4/IPv6 地址生成 Miao 的 `--nopasswd --mode global --vps-host <IP>` 参数，直接传给进程，不经过 shell。启动、手动重启、停止后再启动和崩溃恢复均使用同一选项；关闭自启动和管理员代理总开关仍优先。参数仅保存在 iVnc 进程中，原命令行会随自重启保留，不写入配置文件。

Docker 入口移除固定的参数分隔符，使镜像名后的选项能传给 iVnc；`docker-run.sh` 同步透传位置参数。默认配置仍为 `/etc/ivnc.toml`，默认前台命令仍为 `sleep infinity`；保留自定义前台命令和显式 `--` 分隔方式。无前台命令时也注册退出清理与信号转发，避免只提供 CLI 参数时无法正常停止 iVnc。启动失败与前台命令退出同样清理子进程。

验证结果：

- 后端 lib 45 / bin 47 项通过，覆盖 IPv4/IPv6、无效/缺失/重复参数、实际启动参数、重启/崩溃恢复与代理禁用。
- Docker 入口 9 项隔离测试通过，覆盖镜像入口声明、参数边界、旧命令用法、信号转发、启动失败及退出码；已接入 CI 构建前检查。
- 配套二进制构建成功，主命令与 `run` 子命令的帮助均包含新参数；HTTP/HTTPS 生命周期与真实 Chromium iframe 回归通过。
- Rust 格式、Shell/Python/YAML 语法与 diff 空白检查通过。未发现阻塞问题。

本次无需修改或重新发布 Miao，已有配套协议 v2 产物支持所需参数。Docker daemon 不可用，未实际构建镜像；VPS 参数测试使用替代面板，未连接真实 VPS 或修改宿主机代理。

Miao 的“编辑应用”改用完整后台应用表单，全部字段只读，文本可复制，移除保存按钮、特殊说明和弹窗内的“配置代理”链接；应用列表保留面板、启停、重启和日志入口。API 同时禁止所有内置配置更新，包括自启动，避免仅在界面禁用控件。
