# 新增桌面应用的远程访问配置与 Review

日期：2026-11-15。

## 实施结果

- 添加桌面应用时直接显示“远程访问”，默认关闭。首次开启生成随机密码，也可自行输入或重新生成；前后端一致按 8–256 UTF-8 字节校验。
- 保存前连接地址显示“保存后生成连接地址”，复制按钮禁用。共享保存成功后原地转为编辑状态并保留弹窗，显示真实地址和复制入口。
- 一个保存动作串行完成创建和共享策略写入。应用先创建成功但共享失败时保留 ID 和密码草稿，再次保存更新同一个应用；后台、CLI、远程应用及未开启共享的新增仍按原流程关闭弹窗。
- 创建接口支持可选 `creation_id`，使用 UUID v4 作为该应用的 ID。响应丢失时按确切 ID 核实；不能确认时锁定原草稿并提供重试。重复创建请求不覆盖已有应用，也不按同名应用推断本次创建成功。
- 共享写入响应丢失时读取实际策略核对，避免立即重复提交密码而再次撤销会话。写入已成功但随后的读取失败时保留已确认的保存结果和连接地址。
- 提交期间禁用表单并保留关闭入口；已提交操作继续使用原请求快照，重开同一应用等待操作完成。类型切换保留本次草稿，关闭后重新添加清空草稿和加载状态。
- 更新中英文提示、使用说明、API 文档和本地测试入口；GitHub Actions 没有变化。

## 整体审查

1. **保存目标与重试**：新增响应按 `app.id` 读取；创建 ID 在提交前就纳入待完成写入管理。部分成功后切换为编辑模式，后续请求使用已保存 ID，避免重复创建或把共享配置写给其他应用。
2. **异步隔离**：成功、失败、读取和最终解锁均检查弹窗会话。关闭、重新添加及重新编辑不会让旧回复修改新表单；既有应用的提交快照回归通过。
3. **密码与撤销**：密码草稿仅保存在当前页面内存，未增加浏览器持久化。保留旧版 hash-only 密码留空不变的逻辑；共享读回确认后更新保存基线，后续未改密码时不再写入策略。
4. **运行状态**：创建和保存共享策略均不会直接启动应用。首次启动仍由现有运行逻辑读取共享策略；运行中的应用继续按实际运行方式提示重启，保存后的读回状态也参与判断。
5. **交互和兼容性**：新增与编辑复用同一组控件，保留受 iVnc 管理的内置应用只读条件。补齐加载取消后共享开关状态重置、保存后高级选项恢复，以及焦点管理对 fieldset 继承禁用状态的识别。实际页面截图已检查。
6. **接口兼容**：旧调用省略创建 ID 时继续使用原行为；新增 ID 严格限制格式及桌面类型，不允许覆盖已有记录，不增加数据库迁移。

已验证范围内没有剩余阻塞项。

应用和共享配置仍分库存储，保存不是跨库事务。刷新、关闭页面或服务异常可能中断尚未发出的第二步；已创建应用会保留，可重新编辑补齐共享配置。没有承诺整个操作在页面退出后仍能自动完成。
